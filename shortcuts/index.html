Family shortcut

Calendar sync no longer needs a shortcut or automation. Family Organizer writes dated items straight into the family calendar, which shows in the iPhone Calendar app. Setup is in the app: Settings › This phone › iPhone Calendar. Family Papers below is only for reading papers.

Install Family Papers

If Family Papers is already on the phone, tap Replace (not Add), so there is only one.
